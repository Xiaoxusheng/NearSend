================================================================================
                        局域网快传  {{VERSION}}  使用说明
================================================================================

【它是什么】
    在同一个 Wi-Fi 下，让电脑、手机、平板互相传文件的工具。
    不用数据线，不用微信/QQ，不用网盘，不用注册账号，不连外网。

    一台设备运行本程序当作「中转站」，其它设备用浏览器连上它，就能互相收发文件。


--------------------------------------------------------------------------------
【三步开始用】
--------------------------------------------------------------------------------

    第 1 步   启动服务
              · Windows：双击 启动服务.bat
              · macOS / Linux：打开终端，执行  ./start.sh  （首次可能需要
                先执行 chmod +x start.sh nearsend）

              会弹出一个窗口，里面显示几个网址，形如：
                  → http://192.168.1.28:8787      ← 手机用这个
                    本机访问: http://127.0.0.1:8787  ← 这台电脑自己用这个

              ★ 这个窗口不要关闭，关掉窗口服务就停了。

    第 2 步   在这台电脑上打开页面
              用浏览器打开 http://127.0.0.1:8787
              （从本机打开会自动获得管理权限，可以改设置）

    第 3 步   让手机连上
              手机连接和电脑【同一个 Wi-Fi】，然后：
              · 用手机相机 / 微信扫描网页上的二维码；或者
              · 在手机浏览器手动输入第 1 步里那个 192.168.x.x 的地址

              手机打开后会自动出现在网页的「附近在线设备」里。

    然后就可以：拖文件 → 选设备 → 点发送。对方在手机上点「接受」就开始传了。


--------------------------------------------------------------------------------
【第一次运行可能会遇到的事】
--------------------------------------------------------------------------------

    ▲ Windows 防火墙提示
      第一次启动会弹出「Windows 安全中心警报」，问是否允许访问网络。
      必须勾选「专用网络」并点【允许访问】，否则手机连不上。
      如果当时点了「取消」，可以到
        控制面板 → 系统和安全 → Windows Defender 防火墙 → 允许应用通过防火墙
      里找到本程序（或重新解压再启动一次）补上。

    ▲ 程序窗口一闪就没了
      说明端口被占用了。窗口里会打印具体原因和替代端口，
      可以改用：启动服务.bat 里加上参数，例如
          nearsend.exe -port 8888
      或者命令行执行  nearsend.exe -port 8888

    ▲ 「无法连接到服务」
      先确认那个黑窗口还在、没有报错；再确认浏览器地址里的 IP 和端口
      与窗口里打印的一致。


--------------------------------------------------------------------------------
【打不开怎么办？（按顺序排查）】
--------------------------------------------------------------------------------

    1. 手机和电脑是不是连的同一个 Wi-Fi？
       电脑连网线、手机连 Wi-Fi 也算同一个网，前提是同一个路由器。

    2. 是不是开了「访客网络」或「AP 隔离」？
       很多路由器有「访客 Wi-Fi」「无线隔离」「AP 隔离」之类的开关，
       打开后设备之间互相看不见。把它关掉，或让两台设备都连主 Wi-Fi。

    3. 防火墙有没有放行？（见上面「第一次运行」那条）

    4. 网页打不开但地址没错？
       可以试试在网页「网络诊断」页看具体结论；
       或者换一个地址：启动窗口里通常有多个地址，换另一个 192.168 开头的试试。

    5. 公司 / 学校网络限制了设备互访？
       这种情况建议用手机开热点，让要传文件的两台设备都连这个热点，
       然后重启本程序（会显示热点的地址），再重新打开。


--------------------------------------------------------------------------------
【文件存到哪里了？】
--------------------------------------------------------------------------------

    收到的文件保存在「接收目录」，位置在程序窗口里会打印，默认是：
        程序所在文件夹\nearsend-data\received\日期\发送方名称\……

    也就是说，同一个发送方、同一天发来的文件会放在一起，方便整理。

    在网页的「设置 → 传输设置」里可以改成你想要的目录（例如 D:\我的接收文件）。

    发送方传过来的文件会先完整保存在运行本程序的这台电脑上，
    再由接收方点击「下载」保存到自己设备里。因此这台电脑需要有足够的磁盘空间。


--------------------------------------------------------------------------------
【数据存在哪里？怎么卸载？】
--------------------------------------------------------------------------------

    所有数据都在程序文件夹下的 nearsend-data 文件夹里：
        nearsend-data\nearsend.db     ← 记录（设备、任务、历史）
        nearsend-data\received\       ← 收到的文件
        nearsend-data\tmp\            ← 传输过程中的临时文件
        nearsend-data\admin-token.txt ← 管理令牌

    想彻底清除：先关掉程序，直接删掉整个程序文件夹即可（没有任何注册表残留、
    没有系统服务、没有后台进程）。

    只想清理记录、保留文件：
        网页「传输记录 → 清除记录」（只清记录，不删文件）
        网页「设置 → 存储设置 → 立即清理临时文件」（只清临时文件）


--------------------------------------------------------------------------------
【安全提示（请务必读一下）】
--------------------------------------------------------------------------------

    本程序使用明文 HTTP 在局域网内通信，没有启用加密。
    这意味着：同一个网络里的其它设备，理论上可以截获传输内容。

    · 在自己家里的 Wi-Fi 用，没问题。
    · 在咖啡厅、机场、酒店等公共 Wi-Fi 下，请不要用来传敏感文件。
    · 必须跨不可信网络传敏感文件时，建议先用手机热点组一个临时网络。

    「临时接收箱」功能开启后，拿到链接的人在有效期内可以不经确认直接上传文件。
    请不要把链接发给不信任的人；用完可以在「临时接收箱」里立即关闭。


--------------------------------------------------------------------------------
【页面功能速查】
--------------------------------------------------------------------------------

    发送与接收    拖文件、选设备、点发送；下面能看到当前任务和最近传输
    传输任务      所有任务的进度；点右侧箭头可展开，看到分块、校验、任务 ID
    传输记录      历史记录，可按文件名搜索、按方向（我发的/我收的）和状态筛选
    设备管理      在线设备列表；可以给设备改名、设为可信、断开或移除
    临时接收箱    开一个有时限的「免确认收件入口」，适合让别人给你发文件
    网络诊断      服务状态、连接状态、磁盘空间、哈希校验能力，以及排查建议
    设置          接收目录、并发数、分块大小、大小限制、限速、重名策略等


--------------------------------------------------------------------------------
【几个实用小技巧】
--------------------------------------------------------------------------------

    · 一次可以拖很多文件，也可以整个文件夹拖进去（会保留里面的目录结构）。
    · 要发给多个人：在右侧设备列表里多选几台，然后点发送。
    · 同名文件默认「自动重命名」成 「报告 (1).pdf」，不会覆盖你原来的文件。
      想覆盖或跳过，可以在接收方点「接受」时选择。
    · 传大文件中途断了不要紧：重新发送同一个文件时，已经传过的部分不会重传。
      （注意：如果刷新过网页，需要重新选择一次源文件，浏览器不允许页面记住文件。）
    · 手机端建议传输时保持页面在前台，切到后台或息屏可能会被浏览器暂停。
    · 传输完成后，接收方可在任务里点「下载」保存到本机；
      如果接收方就是这台电脑，也可以点文件夹图标直接在资源管理器里打开。


--------------------------------------------------------------------------------
【命令行参数（进阶）】
--------------------------------------------------------------------------------

    nearsend.exe                    使用默认设置启动（端口 8787）
    nearsend.exe -port 9000         换端口
    nearsend.exe -addr 127.0.0.1    只允许本机访问（最安全）
    nearsend.exe -data-dir D:\快传数据   指定数据目录
    nearsend.exe -verbose           输出详细日志（排查问题用）
    nearsend.exe -version           查看版本

    在 Windows 上想带参数启动：新建一个文本文件，写入
        nearsend.exe -port 9000
    保存为 启动_9000.bat，双击即可。
