## 二、商品描述（主文案）

```
【解决的问题】

你有没有遇到过这些情况：

· 手机里的照片视频想传到电脑，数据线找不到，微信传又压缩画质、还有大小限制
· 两台电脑之间传几个 G 的文件，插 U 盘来回倒腾
· 在没外网的环境（内网、机房、出差住酒店）需要传文件
· 不想为了传个文件去注册网盘账号、不想上传到别人的服务器

这个工具就是干这个的：同一个 Wi-Fi 下，手机和电脑直接互传文件。
不联网盘、不注册账号、不压缩画质、不限文件大小。


【怎么用（真的只要三步）】

1. 在电脑上双击启动，会弹出一个窗口，里面显示一行网址
   例如 http://192.168.1.28:8787
2. 电脑浏览器打开 http://127.0.0.1:8787
3. 手机连上同一个 Wi-Fi，扫一下网页上的二维码

然后就可以拖文件 → 选设备 → 点发送。
对方手机上点「接受」，文件就开始传了。


【功能清单】

✅ 手机、电脑、平板互相传，安卓 / 苹果 / Windows / Mac 都能用
✅ 一次可以拖很多文件，也可以整个文件夹拖进去（保留里面的目录结构）
✅ 一次发给多个人：设备列表里多选几台就行
✅ 大文件分块传输，不吃内存；传 10 个 G 也不会卡
✅ 断了能续：中途断网或关掉页面，重新发同一个文件时会接着传，不重头再来
✅ 每个文件都做 SHA-256 完整性校验，传完会告诉你「校验通过」
✅ 同名文件默认自动改名成「报告 (1).pdf」，绝不覆盖你原来的文件
     也可以选「覆盖」或「跳过」
✅ 传输记录可搜索、可按「我发的 / 我收的」筛选
✅ 有传输速度、已传大小、预计剩余时间
✅ 可以暂停、继续、取消、失败重试
✅ 深浅两套主题，手机上也是完整适配的界面
✅ 手机端扫码即用，不用装任何 App


【界面长什么样】

见下面实拍截图，不是设计稿，是实际运行界面。
（图1 首页 / 图2 手机端收到文件请求 / 图3 手机端界面 / 图4 深色模式 /
  图5 传输任务与校验结果 / 图6 传输记录 / 图7 设置页 / 图8 网络诊断）


【适合谁】

· 经常要在手机和电脑之间倒照片、视频、文档的人
· 家里有 NAS、旧笔记本想当文件中转站的人
· 需要在没有外网的内网环境传文件的（机房、实验室、工厂）
· 不想把文件传到别人服务器的人
· 想给自己或团队做一个「自己的快传」的人


【交付内容】

· 对应系统的程序（Windows 64位 / Windows ARM / Mac 英特尔 / Mac 苹果芯片 /
  Linux 64位 / Linux ARM / 树莓派）
· 使用说明书（中文，图文步骤 + 常见问题排查）
· 一键启动脚本，双击就能用
· 全部源码（Go + React，约 2 万行，含自动化测试）
· 免费远程协助装好，装不上可退


【运行环境】

· Windows 10/11、macOS、Linux（含树莓派）都能跑
· 解压即用，不需要装 Go、Node、数据库，没有任何运行库依赖
· 是一台设备当「服务端」，其它设备用浏览器连它


【先说清楚，避免误会】

⚠️ 只能在同一个局域网内用（同一个路由器 / 同一个 Wi-Fi）。
     它不依赖外网，所以也不能跨城市跨网络传文件——那不是它的用途。

⚠️ 传文件时会先存到运行程序那台电脑上，再由对方下载。
     所以那台电脑需要有足够的磁盘空间。

⚠️ 局域网内是明文传输（没有加密）。
     在家里、自己公司的网络用没问题；
     在咖啡厅、机场这种公共 Wi-Fi 下不建议传敏感文件。

⚠️ 浏览器不允许网页自己扫描局域网里的设备，
     所以设备列表里显示的是「已经连上这个服务的设备」，
     需要对方扫个码或输一下地址，不是打开就自动出现所有设备。

⚠️ 手机浏览器切到后台或息屏时，系统可能暂停传输，建议保持页面在前台。

以上都是这类工具的客观限制，先说清楚，不夸大。


【为什么不做成「一键自动发现」】

因为浏览器出于安全考虑，不允许网页扫描局域网。
能做到「打开就自动列出所有设备」的，只能靠一个需要安装的客户端程序。
如果你确实需要这个能力，可以拍前私信聊，我看看能不能加上。

（本工具已把设备发现模块和网页注册模块分开设计，加原生发现不影响现有功能。）


【关于源码和二次开发】

源码一并交付。技术栈是 Go 后端 + React 前端，结构清晰、注释齐全，
含 70 个后端自动化测试用例。想自己改功能、加需求都可以私信。
```

## 三、备用问答（买家问到直接复制）

**Q：需要联网吗？**
A：不需要外网。它就在局域网里跑，同一 Wi-Fi 就能用，也不上传任何数据到别人服务器。

**Q：支持苹果手机吗？**
A：支持。iPhone 用 Safari 或微信扫码打开就能用，不用装 App。

**Q：能传多大的文件？**
A：默认单文件上限 32G、单次总量 64G，都能在设置里改。

**Q：会不会压缩画质？**
A：完全不会。是原文件传输，还会做 SHA-256 校验，传完能确认文件一模一样。

**Q：传的时候电脑要一直开着吗？**
A：运行程序的那台电脑要保持开着，程序窗口不要关。接收方设备随时可以关页面。

**Q：会不会把我的文件传到网上？**
A：不会。所有流量都在你自己的局域网内，程序不连任何外部服务器。

**Q：能两台手机之间传吗？**
A：可以。只要两台手机连同一个 Wi-Fi，并且都连上这个服务就行。

**Q：Windows 防火墙弹出提示怎么办？**
A：一定要点「允许访问」并勾选「专用网络」，否则手机连不上。说明书里有图解。

**Q：装不上怎么办？**
A：拍前可以先说一下你的系统，我确认能跑再让你拍。装不上可以退。

**Q：能帮我改成我要的样子吗？**
A：可以，源码都在你手里，也可以私信聊定制。

## 六、定价与发布建议

- **定价思路**：工具类 + 源码交付，可以按「一份即交付全部平台版本」定价，
  避免被问「Mac 版要加钱吗」。若按源码单独定价，务必在描述里写明「含源码」。
- **发布时段**：工作日晚 20:00–23:00、周末全天，浏览量明显更高。
- **服务承诺**：写清「装不上可退」能显著降低买家决策成本。
- **不要做的**：不要写「支持所有系统」「绝对安全」「自动发现局域网所有设备」——
  这三条都不成立，容易招来退货和差评。
